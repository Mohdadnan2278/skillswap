# SkillSwap

SkillSwap is a planned college semester project built around a simple idea: everyone can teach and learn.

Students will be able to list skills they offer and skills they want to learn, then find suitable matches. Planned features include scheduling, video conferencing, a credit system based on one credit per hour, and community reputation to help members build trust.

This repository currently contains only the project foundation. The application features above have not been implemented.
