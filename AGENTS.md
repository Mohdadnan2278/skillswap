# Collaboration rules

- The project owner handles backend work. Their friend handles frontend work using Antigravity.
- Work incrementally, one phase and one task at a time.
- Create a task branch for each change and open a pull request targeting `main`.
- Coordinate changes to shared configuration, dependencies, and types before editing them.
- Never commit secrets, credentials, or local environment values.
- Preserve each other's work; inspect existing changes before editing and avoid overwriting them.
